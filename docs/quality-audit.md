# QUI Theme 工程质量与性能审计

日期：2026-10-08。范围：保真画廊、独立 Vue 组件库、资源生成、发布产物及本地质量门禁。

## 工程评价

优化前综合评价约 **5.5/10**：具备 Vue 3、TypeScript 和组件封装基础，能够交付完整原型；对发布包消费、资源重复、生命周期和回归保障的处理不足。这是代码与实测支撑的工程判断，不是 Lighthouse 评分。

| 维度 | 原有表现与问题 | 本轮结果 |
| --- | --- | --- |
| 类型与接口 | 严格类型检查通过，但默认导出声明与运行时不符，事件有效负载类型不完整，公开声明引用未发布的 JSON 类型 | 修复默认导出、统一交互与地区类型、生成完整 JSON 声明，消费检查不跳过库声明并覆盖正反例 |
| 模块设计 | 页面协调器集中 1,295 行，加载、动效、手势、业务分支混杂 | 拆分资源、动效、手势和路由控制器，393 行页面保留生命周期与状态协调 |
| 资源治理 | HTML 内嵌大型图片、状态复制正文、设备数据重复、全量动效和地区数据提前加载 | 内容哈希去重、图片保持原始字节、状态差量保存、数据按路由加载 |
| 发布质量 | 按钮消费保留地区和弹层实现，默认导出缺失 | 注册表延后构造、组件工厂 PURE 标注，二次构建按钮仅 614B gzip |
| 生命周期 | 双弹层提前解锁，定时器与异步回调分散管理 | 共享弹层栈、统一自动关闭、取消信号与版本检查、统一清理 |
| 自动化 | 五个脚本缺少实现，无已跟踪测试或 CI | 接入可执行资源、浏览器、公开 API、产物预算检查及 CI |
| 可访问性 | 首页没有可聚焦元素，图标卡片缺少键盘语义 | zh-CN、主内容角色、导航与图标语义、键盘激活、弹层焦点管理 |

本轮改进后具备可复现的工程保障，约 **8/10**。仍有保真快照带来的大 DOM、较多公共样式及路由专属逻辑；尚无线上真实用户指标和跨浏览器矩阵，不能据此评价为“极致”或满分。

## 实现与取舍

原始快照迁入 `apps/demo/reference`。预处理输出到忽略的 `apps/demo/.cache/public`，构建和类型检查自动生成，干净检出不依赖手工准备。HTML 使用普通扩展名，压缩交给 HTTP 服务器；所有部署资源通过相对 base 解析。

图片、页面、设备状态和动效按内容去重。状态正文与基础页相同时省略正文，运行时恢复基础正文；有差异的正文、浮层和滚动路径完整保留。SVG 内的两张大型栅格图片接近视口后请求。CSS 仅删除同一容器内完全相同的重复规则，保留最后一条，不清理动态类。

构建将路由清单嵌入入口文档，提前发现公共样式、当前页面 HTML 和必要样式。正文和样式并行加载；交互数据、专属控制器、动效和地区数据按需请求。首屏不等待交互数据，首次点击等待依赖，失败可重试。公共样式复用并保持原始层叠顺序。

正文请求使用较高优先级，交互状态与动效 JSON 使用较低优先级。图标页的复制与提示控制器在正文就绪后加载，首屏不用的按钮、控制项索引在首次点击时建立，正文不变时复用。额外测试阻塞控制器请求后立即点击图标，确认首次点击会等待依赖并正常显示提示。

路由切换取消请求，并用版本检查保护样式提交、DOM 更新和异步回调。滚动与拖动更新按动画帧合并，稳定 DOM 查询缓存。图标卡片保留节点顺序和尺寸，离屏使用 `content-visibility`；临近视口切回普通渲染以保持分数像素下的文字和 SVG 绘制。

组件库注册表在 `install()` 内构造；默认导出与命名导出一致。新增 `/regions`，画廊通过公开入口使用地区类型和异步加载器。图标、地区 JSON 成为本地可请求资源，共享成功缓存、失败移除缓存；发布与部署必须保留输出 JSON。构建保留 `no-inline`，避免二次库构建把全部 JSON 重新内嵌进 JS。

发布构建为图标、索引、分类和主题 JSON 生成结构声明，保留精确图标键名而不复制大型 SVG 字符串。消费类型检查关闭 `skipLibCheck`，不依赖消费端启用 `resolveJsonModule`。

共享弹层栈负责滚动锁、最高层 Escape、Tab 循环和焦点恢复。修复外部日期同步、选择器取消后的草稿恢复、Swiper 动态参数与空内容、禁用选项、多实例索引和图标失败重试。画廊选择器确认值在切页后保留，草稿复制数组，取消不改动确认值。按钮新增 `nativeType`，默认 `button`。

删除六个不可达示例文件和专属 CSS，保留独立组件库、公共主题、原始视觉和动效。没有迁移框架或升级既有依赖主版本；增加 PostCSS 用于结构化的精确重复规则处理。

## 环境与方法

Windows、本地生产构建、Node 22.17.1、pnpm 11.22.0、Vue 3.5.43、Vite 8.3.3。浏览器版本及逐次数据记录在 `artifacts/local/performance.json`。全程使用临时静态文件服务器，没有启动开发服务器，没有提交代码。

基线提交：`14a0ebb0250e32271c1941ce127a7c206fe7b8f0`。迁移的 147 个原始文件已与 Git 对象核对：二进制逐字节一致，文本内容一致（Windows `core.autocrlf` 的换行差异归一化后比较）。

性能通过 Chrome DevTools MCP 追踪复核；重复测量使用 Playwright 的 CDP 会话设置相同的 CPU 和网络参数。每个场景创建独立浏览器上下文、清理并禁用缓存，移动视口 390×844、DPR 1、触摸、浅色、4× CPU。Slow 4G 采用 DevTools 预设的 562.5ms 延迟、180,000 B/s 下行、84,375 B/s 上行。每页运行五次取中位数。首次显示定义为正文插入后第二个动画帧；网络体积统计到 networkidle，包含入口文档、脚本、样式及交互数据的压缩正文，不含 HTTP 头。

原有记录为单次本地实验：移动首页 LCP 4.77s；图标软导航内容等待约 44.7s、点击 INP 49ms。它们提供瓶颈证据，但没有五次原始分布，不能与本轮冷加载中位数作严格同比。桌面缓存回访首页 LCP 653ms、CLS 0.009 本来就良好。

## 性能验收

最终生产构建，五次独立冷加载取中位数；下表全部达到所列实验室预算。

| 项目 | 方案目标 | 最终结果 |
| --- | --- | --- |
| 首页 LCP 中位数 | ≤2.5s | **2.052s** |
| 图标页首次显示中位数 | ≤3s | **2.990s** |
| CLS | ≤0.01 | **0**（两个场景各五次均为 0） |
| 首页图标导航交互时延中位数 | ≤200ms | **32ms** |
| 首页初始 JS gzip，包含内联启动脚本 | ≤35KB | **30,815B**（30,315B 外部＋500B 内联） |
| 图标页首屏传输减少 | ≥90% | **96.62%**；整页初始压缩正文 **257,124B** |
| 图标状态 gzip | <2KB | 510B |
| 按钮独立消费 JS gzip，排除 Vue/CSS | ≤1KB | 614B |

首页五次 LCP：1.908、2.476、2.044、2.336、2.052s；图标页五次首次显示：2.955、3.032、2.990、3.006、2.980s。图标页 LCP 中位数为 2.984s。首页初始压缩正文 63,602B，交互时延范围 24–32ms。采集器等待有效的 LCP 观测值，避免把尚未交付的零值计为通过。

图标预算的中位数余量约 10ms，五次中两次超过 3s，不能据此保证每次加载都在 3s 内。一版加载顺序调整前的复测中位数为 3.017s，超出预算；随后调整请求优先级、延后图标专属模块并去除首屏索引扫描。报告采用最终完整五次分布，没有只选最快结果。

加载链最后调整前的 Chrome DevTools MCP 图标页冷加载追踪：4× CPU、Slow 4G，LCP **3.414s**、CLS **0**，13 个请求全部成功；两个离屏栅格图片未请求。该追踪独立于五次测量，不能隐藏其超过 3 秒的结果。图标页保留大 DOM，追踪开销、调度和主机负载仍会影响尾部时延。

代表性交互记录采用 Event Timing；首页点击图标导航用于验收。只测少量交互的实验室值不能代表线上页面 INP。图标直达场景没有交互，其 JSON 中的 `inp: 0` 表示未测，不表示零延迟。没有 CrUX 数据；未计算或宣称完整 Lighthouse 性能分数、TBT、Speed Index。

## 验证记录与边界

- `pnpm check`：已通过类型检查、两个生产构建、13 项资源与浏览器回归、真实 dist 消费、默认导出与完整声明检查。
- 资源测试：39 条路由、两种设备的正文、状态、浮层与滚动路径等价；内嵌图片解码字节一致；所有生成 CSS 资源路径存在。
- 浏览器回归：双弹层滚动锁、Tab 循环、Escape、焦点恢复和卸载；按钮类型与禁用选项；日期外部值与选择器草稿；Swiper 动态参数、空内容及定时器；多实例索引；同一浏览器上下文图标请求失败重试；子目录、键盘导航、快速切页、首次点击数据失败重试；确认值跨路由保留与取消恢复；真实鼠标和触摸滑动、手势中切页。
- 静态视觉：39 条路由 × 390/1280 宽度 × 浅色/深色，共 156 张视口截图，全部通过。与迁移前 Git 构建对比，最大差异像素比例 **0.0122%**，低于 0.1% 门限。
- 交互视觉：12 条代表路由 × 两种宽度 × 两种主题，共 48 组，全部通过。在相同 200ms 动画时间点比较，差异像素比例全部为 **0**。最后的加载与索引调整后，四种图标视口/主题组合再次比较，差异也全部为 0。
- 相同机器、字体、浏览器生成基线与当前截图；语言修正后显式保留原来的拉丁字母和 CJK 回退字体。

截图覆盖视口与代表性打开状态，未穷举全部滚动位置、按钮组合和动画时间点；资源等价测试补充验证完整快照内容。浏览器自动化使用 Chromium，Firefox/Safari 未实测。CI 配置已加入，本地同等命令通过不等于远程 CI 已运行。视觉与性能测量单独运行，避免跨主机字体和 CPU 差异混入常规 CI。

可复现命令：

```sh
pnpm check
pnpm baseline:build <pre-migration-ref>
pnpm baseline:capture
pnpm verify:replica
pnpm verify:interactions
pnpm verify:performance
```

基线构建读取 Git 对象，不切换或修改工作区。后续版本可归档生产产物，通过 `verify:replica --capture --source <directory>` 建立新基线。截图、原始构建、逐次测量和 JSON 报告保存在忽略的 `artifacts/local`。

## 权威依据

- [Vue 官方性能指南](https://vuejs.org/guide/best-practices/performance.html)：控制初始体积、按需加载、稳定性和 tree shaking。
- [Google LCP 优化指南](https://web.dev/articles/optimize-lcp)：提前发现关键资源、减少请求链和渲染延迟。
- [Google Fetch Priority 指南](https://web.dev/articles/fetch-priority)：区分关键正文与后台交互数据的请求优先级。
- [Google 布局优化指南](https://web.dev/articles/avoid-large-complex-layouts-and-layout-thrashing)：集中布局读取、减少布局抖动及离屏渲染成本。
- [Rolldown dead code elimination](https://rolldown.rs/in-depth/dead-code-elimination)：消除注册初始化副作用及正确保留 PURE 标注。
- [Vite 静态资源指南](https://vite.dev/guide/assets.html)：相对资源 URL、资源输出及 `no-inline`。
- [DevTools 网络预设源码](https://github.com/ChromeDevTools/devtools-frontend/blob/main/front_end/core/sdk/NetworkManager.ts)：重复测量采用相同 Slow 4G 参数。
